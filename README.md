# Інтернет-магазин одягу «TrendWave»

Навчальний програмний проєкт з дисципліни проєктування програмного забезпечення.

## Короткий опис
Вебзастосунок для онлайн-продажу одягу з інтелектуальним підбором розміру за параметрами користувача, зручним каталогом та панеллю керування замовленнями і складськими залишками для менеджерів.
